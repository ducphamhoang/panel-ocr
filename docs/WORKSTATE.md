from a warning to a hard error by CI's `RUSTFLAGS: "-D warnings"`.

**This is pre-existing, not caused by the `panel-ocr inpaint` work just landed:**
`git diff --stat 8e75077 f48c071 -- xtask/` is empty — nothing in that commit touches
`xtask` at all. Two independent gaps let it go unnoticed until now:

1. `.github/workflows/ci.yml` triggers only on push to `main` or on a PR (`on: push:
   branches: [main]; pull_request`) — never on push to any other branch. `main` had not
   been pushed to in ~200 commits, so this workflow simply never ran against the
   `v1.2`→`v1.5` development line until this session force-fast-forwarded `main` to catch
   up and pushed it.

   --workspace` (no `--all-targets`) and `cargo test --workspace --all-targets --features
   pc-cli/onnx`, but never the exact combination CI's plain `test` job runs —
   `cargo test --workspace --all-targets` under the *default* (non-`onnx`) feature set,
   which is what makes `xtask`'s onnx-only-reachable items genuinely dead in that build.

**Deliberately not fixed in this session** — user's explicit call (2026-08-11/12): "note
it for next time, don't need to fix it now." If a future session picks this up: the fix

trigger scope. Also worth folding `cargo test --workspace --all-targets` (default
features) into the standing verification bar so this class of gap gets caught locally
